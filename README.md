# Fada TV

Application web (PWA) qui regroupe des films, séries et chaînes **gratuits et légaux**, en français, avec un mode économie de données.

## Mettre l'application en ligne (gratuit)
Le dossier contient tout : `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`.
Il suffit de le publier sur un hébergement statique gratuit (GitHub Pages, Netlify, Cloudflare Pages).
Ensuite, sur Android, ouvrez le lien dans Chrome puis menu ⋮ > « Ajouter à l'écran d'accueil ».

## Sources utilisées (gratuites et légales uniquement)
- Films récents : TV5MONDEplus, et chaînes YouTube officielles de producteurs Nollywood (Omoni Oboli French TV, Maurice Sam TV, Ruth Kadiri 247, Uchenna Mbunabo TV, FAAN TV, Kap Stream, Sonia Uche TV).
- Séries : MARODI TV (Sénégal), AREWA24 (haoussa), TV5MONDEplus, Uduak Isong TV, Bimbo Ademoye TV.
- Direct : Télé Sahel, ORTN, Canal 3 Niger (YouTube officiel), France 24, Africanews, RFI.
- Films classiques : Internet Archive, collections du domaine public uniquement.
