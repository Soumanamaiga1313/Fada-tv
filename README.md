# Fada TV

Application web (PWA) qui regroupe des films, séries et chaînes **gratuits et légaux**, en français, avec un mode économie de données.

## Mettre l'application en ligne (gratuit)
Le dossier contient tout : `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`.
Il suffit de le publier sur un hébergement statique gratuit (GitHub Pages, Netlify, Cloudflare Pages).
Ensuite, sur Android, ouvrez le lien dans Chrome puis menu ⋮ > « Ajouter à l'écran d'accueil ».

## Sources utilisées
- Internet Archive, uniquement les collections du domaine public (feature_films, animationandcartoons, prelinger, silent_films, classic_tv).
- Liens vers des sites officiels gratuits : TV5MONDEplus, France 24, Africanews, RFI.
- Recherches YouTube vers les chaînes officielles (Télé Sahel, ORTN, Canal 3).
